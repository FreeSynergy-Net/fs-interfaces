# Capability names (ADR 0068): ONE list, read by fs-packages (fs_interfaces::capabilities) and planned for the catalog generator
# (fs-catalog/scripts/gen_catalog.py). One line per capability, fields separated by `|`, spaces around them ignored:
#   key | display name | status | description
# key: lower-case dotted machine name (`topic` or `topic.facet`); a topic key is the name of its schema in fs-interfaces
#   (ADR 0068). display name: for people ("Boards" for key `whiteboard`); the pair lives here and nowhere else.
# status: `stable` (the interface exists) or `planned` (named, not built yet; is_known is true, is_planned tells).
# A package states a level `major.minor.patch` (SemVer, read with `semver`) next to the key (provides, requires, recommends). Only append, never rename or remove.
# `#` starts a comment line.

# value.*: a command group without a schema of its own (like label.* and relation.*; otherwise a topic key would be a schema name, line 4). value.* is the general command key for every module with typed properties (form fields-in-groups@1.0.0). The module writes the bare key (value.set) as capability in its catalog/commands.json. The host binds <module>.<key> (first module: settings.value.set) and checks the raw key (without module prefix) against this list (is_known, files read from disk); the full id is not in the list, so the key must be in this list.

value.lock | Lock a value | planned | Locking a typed property, with a reason
